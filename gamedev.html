C++ Project

School Project


Description

"Dungeon Plunders" was a project I worked on with a fully remote team. In this course, students were put into teams in order to create a game. This course was unique as it involved multiple classes being paired together.

The goal of this project was to use C++ in Unreal Engine to create specific features requested by the team. I ended up creating various features related to User Interface, Enemy AI and Navigation, and Player Movement.

This project gave me some excellent insight in what it is like to work with a team in a remote setting. The idea for this project was heavily inspired by a game known as Bloodthief.
