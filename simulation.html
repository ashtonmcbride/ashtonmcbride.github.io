Game Simulation Project

School Project


Description

"Red Handed" was the final project of my degree in Game Development at Northwest Vista College. In this course, students were put into teams in order to compete and simulate an actual game studio. There were different departments within each group including animation, programming, modeling, and more.

Both teams were assigned a game engine to use in order to build a game. My team was assigned Unreal Engine and the other was assigned Unity. While I had previous experience using Unreal, I was certainly not an expert. So, I adapted quickly and was able to lead the programming team successfully.

This project gave me some excellent insight in what it is like to work with a team in a professional setting. The major contributions I made to this project were NPC Navigation, User Interface, and Version Control.

Game Page: https://breakout-studios.itch.io/red-handed
