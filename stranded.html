STRANDED

Personal Project


Description

"Stranded" is a Roblox horror and adventure game that I started working on back in 2020. I have always been a fan of everything horror. The suspense, the music, the thrill, the mystery, the characters, all of it is fascinating to me. Everything about the horror genre motivated me enough to make something that would allow players to experience something special. I wanted people to understand the passion I have for the things that make a genre like horror unique.

Before Stranded, I had experience working on other projects on Roblox (some of which can be seen here). However, I felt that nothing I had made or been a part of really showcased my skills as a builder, coder, designer, and storyteller. I wanted to create something original, exciting, and entirely from the ground up. So, I abandoned everything I had worked on up to that point. I wanted to create a game that told a story. As time went on, I took the opportunity to turn this project into a learning experience. Going into the development of Stranded, I did not know how to code.

As of 2024, I have been able to learn a lot that the Lua programming language has to offer. I have practiced my building and design skills over and over, and have been extremely grateful for the platform that Roblox has given me to be able to create something that I can be proud of. I have taken a lot of inspiration from other games and movies for this project. However, the game is still a work in progress and nothing on this page is final.

I began working on Stranded before generative AI tools became widely used. My main motivation for all of my projects is to challenge myself and see what I am capable of creating, so no AI is used in any of them. AI can certainly be a useful tool for things like programming and processing data, but I do not think that people should rely on it for human creativity. I personally believe that AI lacks the depth of emotional understanding and subjective interpretation that people bring to their creative ideas.

INTRO


For the game's intro, I wanted to create a cutscene that synced up with a soundtrack. I began working on it very early in the game's development, probably going through it more than 200 times to make sure every detail was exactly how I wanted it. Every character animation was made using the Live Animation Creator feature in Roblox Studio. Additionally, each player sees their own character in each cutscene.

CODE SAMPLE

--IF PLAYED, THEN
if ValuesData["Progress"]["CompletedIntro1"] == true then

	CutscenesModule.Menu(Player)

	task.wait(2)
	script.Enabled = false

--IF HAVEN'T PLAYED, THEN
elseif ValuesData["Progress"]["CompletedIntro1"] == false then

	CutscenesModule.Intro(Player)

	task.wait(2)
	script.Enabled = false

end

When a player joins the game for the first time, the intro plays before they can access the main menu. The code above checks to see if a player has already completed the intro from a previous session, and then calls onto a module known as the Cutscenes module to perform a specific function. If the player has played before, they are redirected to the menu with an option that allows them to replay the intro. If the player hasn't played before, they must first complete the intro before they can access the menu. After the intro is completed, a value is saved to the player's data and checked the next time they play.

MENU


Each button on the main menu performs a corresponding action. Players are able to begin playing by pressing "New Game" or "Continue", gain information about the game by pressing "Information", view the game credits by pressing "Credits", or replay the intro by pressing "Replay Intro".

--[Author]: Zen_os
local module = {}

--[[VARIABLES]]--
local Players = game:GetService("Players")
local Lighting = game:GetService("Lighting")
local TweenService = game:GetService("TweenService")
local UserInputService = game:GetService("UserInputService")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Debris = game:GetService("Debris")

local CameraShaker = require(ReplicatedStorage.Local.Modules.CameraShaker)
local GlobalFunctionsModule = require(ReplicatedStorage.Local.Modules.GlobalFunctions)

local Default = 5.291238898038469


--[[MODULE FUNCTIONS]]--
> function module.Menu(Player) ...
end

> function module.Intro(Player) ...
end

return module

The code above is a basic setup of how I structured the Cutscenes module. Every variable is accessed from both module functions, as both the menu and intro deal with elements from the Players, Lighting, TweenService, UserInputService, ReplicatedStorage, and Debris services. The GlobalFunctions module takes care of common functions such as disabling player movement, resetting lighting, muting sounds, etc. The amount of code in a Cutscenes module function depends on the length of the cutscene.

MENU FUNCTION

function module.Menu(Player)

	local Character = Player.Character
	local HumanoidRootPart = Character:WaitForChild("HumanoidRootPart")
	local Humanoid = Character:WaitForChild("Humanoid")

	local BHS = Humanoid:WaitForChild("BodyHeightScale")
	local BTS = Humanoid:WaitForChild("BodyTypeScale")
	local BPS = Humanoid:WaitForChild("BodyProportionScale")

	local Height = BHS.Value*(4 + BTS.Value*math.pi/2*(1 - 1.2/math.pi*BPS.Value)) + 1

	HumanoidRootPart.Anchored = true
	Character.Archivable = true

	--IF TALLER THAN DEFAULT, THEN
	if Height > Default then

		local NewHeight = Height - Default

		--RAISE FIXCHECK HEIGHT
		local NewYPosition = FixChecks.MenuFixCheck.Position.Y + NewHeight
		FixChecks.MenuFixCheck.Position = Vector3.new(X, NewYPosition, Z)

	--IF SHORTER THAN DEFAULT, THEN
	elseif Height < Default then

		local NewHeight = Height - Default

		--LOWER FIXCHECK HEIGHT
		local NewYPosition = FixChecks.MenuFixCheck.Position.Y - NewHeight
		FixChecks.MenuFixCheck.Position = Vector3.new(X, NewYPosition, Z)

	end

	...

end

One of the greatest challenges I faced when creating this game was determining a player's height. Ever since Roblox allowed users to edit their own character's height and scale, figuring out how to position the player in each cutscene was difficult. Since I was using a very specific position for a character's model (which I call a FixCheck), a player's character would often be too low in the ground for being too tall or too high above the ground for being too short. In the Cutscenes module, a very specific number is assigned to a variable "Default" (5.291238898038469). This is the exact height of a default block avatar rig. In both module functions, a formula is used to calculate a player's height based on their BodyHeightScale, BodyTypeScale, and BodyProportionScale. Then, each character position (FixCheck) is adjusted based on whether the player's avatar is taller or shorter than the default value. The code above is an example of how this process works for the character's position in the menu.

LEVEL DESIGN

THE AGENCY (LOBBY)

❮
❯
1/58

The Agency is one of the biggest and most complex builds I have ever made on my own. I took heavy inspiration from Dev Rel Development's 8th Annual Bloxy Awards. The Agency consists of multiple sectors, including the Main Hall, Artifact Gallery, Entity Chambers, Offices, Corridors, and the Core. I have spent many years putting this lobby together, and it is arguably one of my best builds.

❮
❯
1/5
There are many similarities between the facility I created and the build I took inspiration from. I wanted to expand on the original design and make The Agency extremely large in order to encourage exploration from players. I have always been a fan of adventure and exploration games on Roblox, especially the 2017 and 2018 Egg Hunts.

Similar to Dev Rel Development's lobby, announcements with random dialogue play over the lobby intercom. Coins are scattered throughout many of the different sectors, rewarding those who enjoy exploring. There are many secrets to find and quests to complete in the Agency. Randomly-generated NPCs that players can interact with also roam around the lobby, allowing players to complete side quests.

CHARACTER DESIGN

STRANDED

The game's antagonist. A powerful sorcerer with an unknown origin. Almost every detail about this individual is either missing or redacted. His real name is unknown and his motives are unclear. Goes by the alias "Stranded" and is known to be the primary enemy actively working against The Agency.

The game's title comes from this character, which was made after I learned I had created an alternate account on Roblox with the username of StrandedBeneath. I have no recollection of creating this account, and I was amazed to find that it was registered on the exact same date as my main account. The username of this account is what first gave me the idea to start working on my own horror game, but more on the early development of this project later.

TREASURE

The antagonist's main accomplice. Unknown origin. Similar to his partner, almost every detail of this individual is either missing or redacted. His real name is unknown and his motives are unclear. Goes by the alias "Treasure" and is also known to be actively working against The Agency.

While on a search for other accounts I may have registered in the past, I came across one with the username TreasureTechnique. Like StrandedBeneath, I have no memory of creating this account. Interestingly, I made this account a few months before the other two. I liked the username enough to want to have him be involved in the story.

AGENT ZEN

Leader of The Agency. His ultimate goal is to put an end to Stranded's antagonism by containing all of the dangerous entities from other worlds before Stranded will be able to use them to cause irreversible damage to his world.

This character was inspired by my main Roblox account. I have always been interested in things like secret agents and espionage, so I wanted my character to resemble those themes. I also wanted to have a character that could lead players and explain their objective to them. A lot of games that I have played in the past don't offer a whole lot of context or details on what to do next, which can be frustrating. Agent Zen will be one of the more important characters throughout the story.

ENTITY: AZALEA

Queen of the Woodlands. Once a divine being of pristine elegance, Azalea was the marked entity that reigned over the mystical lands of Aezamund. Despite her captivating and enchanting facade, her veil of corruption is often concealed.

Queen Azalea is one of my first original characters. I wanted to give her a sort of mother nature vibe considering the landscape she would reside in. It was exciting being able to experiment with character design in Roblox Studio because it was something I had not tried before. She is definitely one of the favorite entities among my friends and I, and I am excited to see what people will think of her in the game.

ENTITY: THE WATCHER

Knight of Iakudell. Cursed to only observe those who enter his realm, The Watcher was the last remaining survivor in the kingdom of Iakudell.

The Watcher is the entity that holds the most emotional value to me. I have redesigned him multiple times, with this final design being my favorite. Iakudell is a very desert-like realm, so I wanted the entity of this dimension to resemble a deceased pharaoh or emperor. His design as well as his story is heavily inspired by "The Chaser" from the Saint Abida Tribe's Realm of the 9 Portals.

ENTITY: OMNIS

Celestial deity of Orion. Forever confined to the expanse of his realm, Omnis was banished to Orion for unknown reasons. A storyteller by heart, he enjoys narrating stories to those that find themselves before him.

I wanted to create a character that could act as a narrator and explain the game's story to the player. Whether it was an event that occurred, a character's backstory, or explaining how a player died, I did not want to leave players feeling confused. I plan on leaving enough room in the story up to interpretation to allow players to interpret it in their own way.

ENTITY: VORATH

Lost soul of Whitmore. Summoned as a malevolent angel of shadows and whispers, Vorath was bound to the Whitmore Manor through a dark pact. His name strikes fear into the hearts of those who dare speak it, a reminder of the darkness that lurks within every soul.

The design for Vorath comes from one of my good friends, Charlie. He is a phenomenal artist and actually offered to draw this entity for Stranded. You can view his original drawing by clicking on Vorath's image above. I plan on reworking Vorath's story and making him look more accurate to his drawing.

USER INTERFACE

LOADING SCREEN


After preloading the game's essential content, the loading screen displays in-game screenshots, useful tips, and a loading mask icon to the player. The in-game screenshots as well as the tips are randomized every time a player is brought to the loading screen. I plan on revamping a lot of the current UI, including the loading screen.

HUB GUI


The Hub GUI consists of a badge list, information tab, and daily shop. This interface can be accessed directly from the menu or inside any level, apart from cutscenes. The badge list allows players to view descriptions of achievements they have made and see the date of when they collected a badge. The information tab includes what a player's objective is, explanations of the game's features, a feedback system, and more. The shop tab allows players to purchase in-game cosmetics in a shop that refreshes every 24 hours.

INSPECTING


When players collect artifacts or contain entities, they will be able to inspect them. If a player hasn't yet contained or collected an artifact, question marks appear in place of each piece of information. Lock symbols also appear on uncontained entity tubes indicating that specific entities still need to be contained. This feature will be useful for character details, dates contained, and more.

INTERACTING


Randomly-generated NPCs can be found roaming around The Agency, allowing players to interact with them. Some NPCs allow players to accept side quests to complete for additional coins and XP. Clicking during a NPC's dialogue skips the animation to the end of the dialogue.

EARLY DEVELOPMENT

Around 2018 and 2019, mysterious games known as "Roblox Myths" were an extremely popular subgenre on Roblox. Myth hunters loved to solve puzzles and unravel the hidden secrets behind these places. I enjoyed exploring myth games myself, so I was motivated to make my own after discovering one of my accounts with the name StrandedBeneath.

❮
❯
1/5
I ended up creating about a dozen of myth games surrounded by this persona in order to attract players that loved a good mystery. The main game consisted of a log cabin in the middle of some snowy woods with a few puzzles that players could go around and solve. Although the game was extremely basic, I had a lot of fun experimenting with all sorts of horror elements.

While the myth games I made never grew super popular, they did gain some traction in the myth hunting community. One myth hunter named Detective_Phillips documented a few clues in a game of his (P&B Private Investigation Services) that were related to the games that I made. Another hunter named I_nsomniac drew some fan art of the StrandedBeneath persona. It was small instances like these that motivated me to expand on this idea and create a fully fleshed out horror experience and see what else I was capable of creating.

❮
❯
1/3
Over the next few years, I came up with some rough ideas of what I wanted my horror game to look like. I still wanted to include a lot of the same elements as my original myth games, such as the masked persona and black/white saturation, but I also wanted to create something that would appeal to those who weren't very familiar with Roblox myths. I wanted to create a more immersive experience for people while still allowing for a sense of mystery to the story. Ultimately, I wanted to create something that was interesting but also did justice to my original ideas.

❮
❯
1/4
After deciding to expand my myth games into a horror game, I had the opportunity to practice things like character and level design. The Watcher and Queen Azalea were among the first entities I made for Stranded, and their earliest designs can be seen in the images on the right. I hope that one day players will grow to love and resonate with the story and characters that were made for this game.

❮
❯
1/3
That's about it for Stranded. This project is my proudest creation, as it has allowed me to grow as a designer, builder, programmer, and storyteller. I have big plans for this game despite a lot of it still being unfinished. I will be forever grateful to my friends and fans that have supported me over the years, especially those who have watched me give up on old projects to pursue this one.
